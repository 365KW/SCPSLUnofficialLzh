# SCP: SL 文言譯（未具）

社羣制文言譯本，未具亦未止。

## 載

取庫案，揀 `lzh` 至戲之案夾 `Translations`。<br>

下傳：<br>
```shell
git clone https://github.com/365KW/SCPSLUnofficialLZH.git
```

## 協

蓋文言難譯，置通則：<br>

- [法式](https://docs.github.com/zh/get-started/exploring-projects-on-github/contributing-to-a-project)
- [章法通則](https://zh-classical.wikipedia.org/wiki/%E7%B6%AD%E5%9F%BA%E5%A4%A7%E5%85%B8:%E7%AB%A0%E6%B3%95)

俗字、機譯皆不納。<br>

> 協，須「叉」此庫。<br>
> 訂而提交，起合併書。<br>

呈交須以【修】【補】作頭。

式如下：<br>
- 「修」者，訂正也。改謬而正文。
- 「補」者，補正也。增文而訂正。

凡例：<br>
```
【修】訂Items.txt謬
```
